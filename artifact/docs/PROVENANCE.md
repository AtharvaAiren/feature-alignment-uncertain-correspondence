# Provenance and public-source policy

This is a fresh anonymous artifact assembled from authenticated terminal
campaign exports. Development Git history, remotes, server launchers, queue
states, failures, and recovery logs are not part of the submission.

Scientific values are unchanged. Absolute machine paths and private host or
account strings in serialized metadata were replaced with portable
`artifact://` references. `provenance/SANITIZATION_MANIFEST.json` maps each
changed file's execution-time SHA-256 to its public SHA-256 and records the
replacement count. Sanitized records are therefore scientifically equivalent
but intentionally not byte-identical to their private originals.

The paired-recovery follow-up retains its complete 160-unit scientific panel,
terminal aggregate, reconstruction verification, and prospective protocol.
The compact `results/campaign/` directory retains the authenticated execution
manifests required by the public source-integrity tests; it is provenance for
the primary campaign, not an additional experiment.
Large feature arrays are omitted but remain bound by recorded digests.
`SHA256SUMS` authenticates the public release itself.
